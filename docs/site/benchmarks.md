# Benchmark reports

`make bench-report` regenerates the projection quality and k-means numbers. The import table, the
ANN table, the BLAS numbers, the `transform` 72%, and the `init` 6.4x and 1.2x numbers are not
generated by this command; those are measured separately. Run:

```bash
make bench-report
```

It writes a dated report under `docs/bench/` recording the machine, the load average and every
package version the numbers were measured on, so that a slow row can be attributed to a loaded
host rather than to a change in the library. The most recent report follows in full.

!!! note "Comparing two reports"
    Only compare reports whose **Machine** rows match. The quality columns (overlap@15, global
    corr) are deterministic and comparable everywhere; wall times are not.
