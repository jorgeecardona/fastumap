# Benchmark reports

Every number this site and the README quote is generated by one command, not pasted by hand:

```bash
make bench-report
```

It writes a dated report under `docs/bench/` recording the machine, the load average and every
package version the numbers were measured on — so a slow row reads as "that box was busy" rather
than "the library got slower". The most recent report follows in full.

!!! note "Comparing two reports"
    Only compare reports whose **Machine** rows match. The quality columns (overlap@15, global
    corr) are deterministic and comparable everywhere; wall times are not.
